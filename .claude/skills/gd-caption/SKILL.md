# gd-caption — 캡션

## 순서
1. `STYLE.md` 의 **캡션 형식** 1~7번을 그대로 따른다 (첫 두 줄 후킹 + 🥚 → 오늘의 황금알 → ✔ 소제목 3~4개 → 📌 핵심 → 댓글 질문 👇 → 고정 마무리 → 해시태그 7개 안팎, 마지막 `#골든덕랩`).
2. 첫 두 줄은 `/gd-hook` 채점 기준으로 쓴다. **'더 보기' 전에 보이는 건 첫 두 줄, 한글 약 70자**다. 그 안에 숫자나 구체적인 대상이 하나 있어야 한다.
3. 시리즈별 필수 문구
   - ETF: "과거 수익률은 미래 수익을 보장하지 않으며, 특정 종목 추천이 아닌 정보 제공이에요." + 기준일
   - 현금흐름: "배당은 확정된 금액이 아니며, 특정 종목 추천이 아닌 정보 제공이에요." + 기준일·세전 표기
4. 완성한 캡션을 원고 JSON의 `caption` 에 넣고 점검한다:
   ```
   python3 caption_check.py <원고.json>
   ```
   `ERROR` 는 반드시 고치고, `WARN` 은 이유가 있으면 그대로 둬도 된다. 결과를 사용자에게 한 줄로 알린다.
5. 마지막으로 `/gd-human` 기준(AI 말투·긴 줄표)으로 한 번 훑는다.

## 하지 말 것
- 게시 시간 적기, 오픈채팅·카카오톡 안내, "받아가세요" 자료 배포 문구 (STYLE.md 금지 사항)
- 해시태그를 첫 두 줄에 넣기, 같은 태그 반복
- 댓글 유도 질문을 두 개 이상 넣기 (행동 요청은 하나만)
