# gd-reply — 댓글 답글

내 게시물 댓글에 빨리, 성의 있게 답할수록 노출이 늘어난다. 하지만 댓글마다 가치가 달라서 **먼저 나누고, 그다음 쓴다.**

## 입력
사용자가 댓글을 붙여넣는다(아이디 포함이면 좋음, 캡처도 가능). 브라우저로 긁어오지 않는다.

## 1단계: 분류하고 개수 말하기
| 분류 | 어떤 댓글 | 답글 |
|---|---|---|
| **키워드** | 게시물에서 요청한 단어 | "DM 확인해 주세요 🥚" 류, 문구는 여러 개 돌려쓰기 |
| **고민** | 자기 돈 문제를 털어놓음 | 공개 답글로 일반 정보 한두 줄 + 다음 편 예고 정도. 개인 상담·상품 권유 금지 |
| **질문** | 많은 사람이 궁금할 질문 | 짧게 답하고 **다음 카드뉴스·골든튠 주제 후보로 따로 적어 둔다** |
| **보충** | 정보 추가, 반론 | 가장 길고 성의 있게. 틀린 건 정중하게 바로잡기 |
| **응원** | 🔥, 좋아요, 친구 태그 | 3~8자 짧게 ("고마워요 🦆") |
| **스팸** | 광고, 리딩방, 악의적 | 답하지 않음. 숨기기/신고 권장 |

## 2단계: 답글 쓰기 (키워드 → 고민 → 질문 → 보충 → 응원 순)
- 친근한 존댓말, 이모지는 0~1개 (🥚 🦆 💛)
- **절대 금지**: 특정 종목·상품 추천, "사세요", 수익 보장, 오픈채팅·카카오톡 안내(STYLE.md)
- "투자는 본인 판단이에요"를 매번 붙이지 않는다. 종목을 직접 묻는 답글에만 자연스럽게.
- 같은 문장 반복 금지. 키워드 답글은 최소 5가지 변형을 돌려쓴다(스팸 판정 방지).

## 출력
```
댓글 32개 · 키워드 20, 고민 2, 질문 3, 보충 1, 응원 5, 스팸 1

[질문] @abc: 배당 ETF는 언제 사야 해요?
→ 배당락일 전에 갖고 있어야 받아요! 날짜 고르는 법은 다음 편에 정리해 볼게요 🥚
...
다음 편 주제 후보: 배당락일 / ISA로 ETF 사면 뭐가 좋아요?
```
"좋아"라고 하면 질문 목록을 `CURRICULUM.md` 에 주제 후보로 추가할지 묻는다.
