# gd-human — AI 티 지우기

## 1단계: 기계적으로 지울 것 (무조건)
- 긴 줄표 `—`, 중간 줄표 `–` → 쉼표·마침표로 바꾸거나 문장을 나눈다
- 보이지 않는 문자(U+200B, U+200C, U+FEFF), 줄바꿈 안 되는 공백(U+00A0)
- 영어식 따옴표 `“ ”` 남발, 의미 없는 콜론 나열
`python3 caption_check.py <원고.json>` 의 "AI 흔적" 항목으로 확인한다.

## 2단계: 말투 고치기
| 이런 표현 | 이렇게 |
|---|---|
| 결론적으로, 요약하자면 | 삭제하고 바로 말한다 |
| ~에 대해 알아보겠습니다 / 살펴보겠습니다 | 바로 첫 번째 내용으로 시작 |
| 다양한 측면에서, 중요한 역할을 합니다 | 무엇이 어떻게 중요한지 숫자로 |
| ~하는 것이 중요합니다 | ~하세요 / ~해야 손해 안 봐요 |
| 번역투 "~를 가지고 있다", "~에 의해" | 있어요 / ~가 |
| 모든 문장 끝이 "~입니다." | "~해요", "~거든요", 질문 섞기 (STYLE.md: 친근한 존댓말) |

## 3단계: 리듬
- 문장 길이를 섞는다. 긴 문장 다음에 짧은 문장. "딱 3개예요." 같은.
- 한 슬라이드 안에서 같은 어미가 3번 연속이면 하나를 바꾼다.
- 추상적인 문장이 2줄 이상 이어지면 예시나 숫자 하나를 넣는다.

## 하지 말 것
- 사실·숫자·면책 문구는 건드리지 않는다. 말투만 고친다.
- 고칠 곳을 억지로 만들지 않는다. 문장 구조를 바꿔야 하는 곳은 표시만 하고 사용자에게 묻는다.
- 결과 끝에 "고친 곳 N군데: 줄표 2, 상투어 1, 어미 반복 1" 처럼 한 줄로 알린다.
