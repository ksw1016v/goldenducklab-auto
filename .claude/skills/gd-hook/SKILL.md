# gd-hook — 첫 3초 문구

카드뉴스는 표지 한 장, 릴스는 첫 2초에서 넘길지 말지가 정해진다. 본문보다 여기에 시간을 쓴다.

## 순서
1. `STYLE.md` 를 읽는다. 금지 표현(수익 보장·종목 추천·오픈채팅 등)은 후킹에서도 금지.
2. 아래 공식 중 **서로 다른 공식 3개**로 후보를 쓴다. 각 후보마다 `말로 하는 문장`(캡션 첫 줄·릴스 음성)과 `화면 문구`(표지 title, 12자 이내 한 줄)를 따로 쓴다.
3. 채점표로 100점 만점 점수를 매기고 높은 순으로 보여 준다. 1등이 50점 미만이면 다시 쓴다.
4. 사용자가 고르면 그 문구로 cover 슬라이드(`kicker`·`title`·`sub`)와 캡션 첫 두 줄을 채운다.

## 공식 (골든덕랩용)
| 공식 | 틀 | 예시 |
|---|---|---|
| 숫자 결과 | ○○ 했다면 지금 얼마? | VOO 월 10만원씩 10년, 지금 얼마일까요? |
| 손해 고백 | 이걸 몰라서 ○○원 날렸다 | 연말정산 이거 하나 몰라서 30만원 덜 받았어요 |
| 흔한 착각 | ○○, 사실 이렇게 하면 손해예요 | 적금 풍차돌리기, 이자가 생각보다 적은 이유 |
| 비교 | A vs B, ○년 뒤 차이 | 적금 vs 배당 ETF, 10년 뒤 얼마나 다를까? |
| 필요 금액 | ○○ 받으려면 얼마 필요? | 매달 100만원 배당 받으려면 얼마 필요할까요? |
| 아무도 안 알려 줌 | 은행에서 안 알려 주는 ○○ | 통장 쪼개기, 은행이 먼저 말 안 해 주는 순서 |
| 초보 질문 (골든튠) | 엉뚱한 질문 + (주제) | S&P500은 먹는 건가요? (지수 투자) |
| 체크리스트 | ○○ 전에 꼭 볼 3가지 | 투자 시작 전에 꼭 정할 3가지 |

## 채점 (합 100점)
- **구체성 30**: 숫자·금액·기간·이름이 들어 있나. "많이", "엄청" 같은 말은 감점
- **나와의 관계 25**: 읽는 사람의 돈·상황으로 바로 연결되나 (질문형, "내 통장")
- **앞쪽 배치 20**: 핵심어가 첫 10자 안에 있나. 인사·"오늘은"으로 시작하면 0점
- **궁금증 15**: 답을 다 말하지 않고 넘기게 만드나
- **짧음 10**: 말하는 문장 25자, 화면 문구 12자 이내

**탈락 사유(무조건 0점)**: 인사로 시작 / "스크롤 멈추세요" / 수익 보장·확정 표현 / 특정 종목 매수 권유 / 근거 없는 숫자

## 규칙
- 숫자는 지어내지 않는다. 모르면 `{{확인 필요: 수치}}` 로 두고 웹 검색으로 확인한다.
- 초등학생도 이해할 단어. 전문용어는 쉬운 말로 풀어 쓴다(골든튠은 특히).
- 결과는 이렇게 보여 준다:
```
후보 (점수순)
 82  숫자 결과   말: VOO 월 10만원씩 10년, 지금 얼마일까요?   화면: 10년 모으면 얼마?
 71  비교        말: ...                                    화면: ...
 48  체크리스트  말: ...                                    화면: ...  ← 약함: 구체성
```
